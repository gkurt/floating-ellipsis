Balanced gaps

Dropping an ellipsis between two arbitrary letters leaves lopsided space, because every glyph carries its own side bearings. floating-points measures the ink and evens it out. By default it matches the gap between the dots themselves, so the ellipsis reads as part of the rhythm.

Paths, hooks and tooltips

The instance exposes whether text is truncated, what was left out, the line boxes and the exact ink box of the ellipsis. Enough to build a tooltip that lines up letter for letter, or one that only answers the ellipsis.
